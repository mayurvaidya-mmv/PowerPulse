PowerPulse Overview

Advanced Smart Energy Monitoring & Industrial Analytics.

PowerPulse is a comprehensive energy dashboard designed for real-time visibility into power infrastructure. By consolidating complex three-phase data from grid and generator sources, we provide actionable insights to detect anomalies, reduce downtime, and optimize costs.

Core Capabilities

Real-Time IoT

Streaming metrics via AWS IoT Core and MQTT.

AI Analytics

Summaries by AWS Bedrock & OpenAI.

Dynamic Alerts

Threshold monitoring with instant SNS alerts.

Downtime Tracking

Precise uptime and switching event logs.

Technology Stack

Node.js AWS IoT Core DynamoDB Bedrock / OpenAI Chart.js Socket.io PM2 Deployment
